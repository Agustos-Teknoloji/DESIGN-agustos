Web screens

One reference page per screen type, rendered live from screens/. Each carries its family's chrome. The rules under each frame come from the screens table in the registry, the same table the kit and the checker read.

Chrome follows the family: websites use the top menu and the footer, product UI uses the sidebar. Marketing, catalog, content, and document screens are light. Only product UI allows dark; open the app shell and use its theme control.

States

Every interactive state in both themes, from the states table in the registry. Text clears 4.5:1; borders, logos and the focus ring clear 3:1. The build refuses a pair below its floor. In the dark theme a hover dims the ink instead of turning it red, and the footer and the closing band stay light. Pressed buttons move 1px down; disabled controls are gray and do not react.
