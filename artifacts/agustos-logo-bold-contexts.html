Logo approach board / May 2026

Existing logotypes and bolder proposals, tested in the places the mark has to survive.

The finalized system uses Inter Tight 650. This board keeps the Laz Güneşi, lowercase wordmark, brand color, and symbol spacing constant, then compares the older light control against the bold candidates in real usage sizes.

Previous control Inter Tight 300, the lighter lockup before this finalization.
Existing directions Plus Jakarta 300 and Bricolage 300, included as familiar references.
Bold tests Mostly 650-730 weights, not black, so the logo stays compact and refined.
Context first Desktop header, mobile header, document, dark footer, and brand-family checks.

04 / Read

My read after seeing them in context.

The bold direction works, but the useful range is narrower than a normal font-weight menu suggests.

Best default: Inter Tight 650

It keeps the current system intact and fixes the main weakness: the wordmark now has enough presence at 16-20px.

Most assertive: Inter Tight 730

Good if the brand should feel more anchored and commercial. I would avoid going heavier than this.

Most character: Bricolage 700

Worth keeping as the expressive alternative. It is more memorable, but less system-neutral across the portfolio.
