# Office Templates & Working Documents

Generated by `build_templates.py` from `brands.json`. The deliverables live under
`exports/<brand>/` (office, swatches, email, guidelines). This file explains how to
turn the two generated Office files into native templates for every app you use.

## What's generated (per brand)

```
exports/<brand>/office/<brand>-template.pptx      PowerPoint deck (16:9, 4 styled slides)
exports/<brand>/office/<brand>-letterhead.docx    Word letterhead (A4, logo header + footer)
exports/<brand>/swatches/<brand>.ase              Adobe swatches (Illustrator/Photoshop/InDesign/Affinity)
exports/<brand>/swatches/<brand>.clr              Apple color list (macOS system color picker)
exports/<brand>/email/<brand>-signature.html      Email-safe signature (self-contained)
exports/<brand>/guidelines/<brand>-brand-guidelines.pdf   Shareable 4-page guidelines
```

## Use the two Office files across all four surfaces

The `.pptx` and `.docx` are the seeds — every other app imports them.

| App | How |
|---|---|
| **PowerPoint** | Open `<brand>-template.pptx`. Optionally save as `.potx` (File → Save As → PowerPoint Template). |
| **Keynote** | Open the `.pptx` in Keynote → it converts → **File → Save as Theme…** → appears in the theme chooser. |
| **Google Slides** | Upload the `.pptx` to Drive → **Open with → Google Slides** (converts to editable). Inter / Inter Tight are in *More fonts*. |
| **Word** | Open `<brand>-letterhead.docx`. Optionally save as `.dotx` (template). |
| **Pages** | Open the `.docx` in Pages → **File → Save as Template…** → appears in the template chooser. |

**Install the fonts first** (`../fonts/`) or these render in a fallback face. See `../fonts/README.md`.

## Swatches

- **`.ase`** — Illustrator/Photoshop/InDesign: Swatches panel → menu → *Open Swatch Library → Other Library…*. Affinity & Figma (plugin) read it too.
- **`.clr`** — macOS: drop into `~/Library/Colors/`, then the palette shows in the system color picker's *Color Palettes* tab (the third icon).

## Email signature

Open `<brand>-signature.html` in a browser to preview, then copy it into your mail
client's signature editor (Apple Mail, Gmail, Outlook all accept pasted HTML). Replace
`{{NAME}}`, `{{ROLE}}`, `{{PHONE}}`. The logo is embedded, so it travels with the message.

## Regenerating the guidelines PDF

The PDF is rendered from `<brand>-brand-guidelines.html` (which embeds the bundled
fonts and the generated lockups). To rebuild after an edit:

```bash
# from the repo root, using the gstack browse tool:
B="$HOME/.claude/skills/gstack/browse/dist/browse"
$B goto "file://$(pwd)/brand/exports/agustos/guidelines/agustos-brand-guidelines.html"
$B pdf brand/exports/agustos/guidelines/agustos-brand-guidelines.pdf --prefer-css-page-size --print-background
```

(Any headless-Chrome "print to PDF" works; A4 page size is set in the HTML's `@page` rule.)

## Maintenance

Same contract as the rest of the kit: edit `brands.json` (or the guidelines HTML
template in `build_templates.py`), then re-run `build_templates.py`. Don't hand-edit the
generated files under `exports/` — your changes get overwritten on the next build.
