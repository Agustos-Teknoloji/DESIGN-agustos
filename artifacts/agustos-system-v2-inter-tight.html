Ağustos Design System · v2.0 · Inter Tight + Inter

One paired family. Two scales of presence. Built to last.

Inter Tight handles every display surface — logotype, hero, headings, eyebrows, UI labels, dashboard numbers. Inter handles every paragraph and inline element. JetBrains Mono carries code. The system fallback resolves to the user's native UI font in any context where the web fonts don't load. Twenty-four tokens, three families, one register from favicon to footnote.

Display

Inter Tight

Logotype, hero, h1–h4, eyebrows, UI labels, table headers, badges, dashboard numerals. Variable wght 100–900.

Body

Inter

Paragraphs, em, strong, links, lists, blockquote, dl, footnote, figure caption. Variable wght 100–900 with italics.

Mono

JetBrains Mono

Inline code, code blocks, file paths, hex codes, technical identifiers. Tabular figures, ligatures off in tabular contexts.

Premium luminaires, mid-tier pricing.

Pataraz delivers project-grade fixtures without the project-grade markup. Designed for professionals; specified to last.

When to use which

.type-hero — Big Hero

Landing pages, brand portfolio pages, launches, press announcements. The page-defining headline. Inter Tight at weight 300 with tight tracking gives a couture feel without going fragile. Pair with optional eyebrow + italic deck. One per page, maximum.

.type-hero-md — Medium Hero

Inner-page headers, section openers, feature blocks. A confident statement that yields the page-defining role to .type-hero. Weight 400 (Regular) gives slightly more presence at smaller scale; tracking eased to -0.032em for legibility.

Editorial · Long-form Turkish

Inter Tight headlines, Inter body, full token coverage

Bayilik · Aydınlatma · Mayıs 2026

Işığın mimariyle buluştuğu yer.

2009'dan bu yana Türkiye'nin önde gelen tasarım stüdyolarıyla. Yazan: Emre Güneş, Ağustos Teknoloji.

Ağustos Teknoloji, on iki uluslararası aydınlatma markasının Türkiye temsilcisidir. Soraa, CoeLux, Xicato ve diğer markalarımızla birlikte; mimar, iç mimar, peyzaj mimarı ve aydınlatma tasarımcılarına proje bazında danışmanlık sunuyoruz.

Yaklaşımımız basit: doğru ışık, doğru yerde, doğru zamanda. Bu nedenle her projede spesifikasyon disiplini ve uzun vadeli teknik destek birlikte yürür.

Çalışma Yaklaşımımız

Her proje, mekânın ihtiyaçlarına özgü bir okumayla başlar. Spesifikasyon süreci üç adımda ilerler:

  1. Aydınlatma briefinin oluşturulması
  2. Ürün önerileri ve teknik dosyaların paylaşımı
  3. Uygulama desteği ve devreye alma

CoeLux · Yapay Gökyüzü

CoeLux, mekâna gerçek gökyüzü algısı taşıyan benzersiz bir teknolojidir. Modüller CRI > 95 değeriyle, 240 m2'lik salonlarda 850 lümen/m2 seviyesinde çalışır. CO2 emisyonu konvansiyonel sistemlere göre belirgin biçimde düşüktür.

İyi aydınlatma, fark edilmediği zaman en iyisidir. — Richard Kelly, 1952

Aydınlatma, mimarinin sessiz dilidir.

Bayilik fiyatları

CoeLux LS modülü: 3.500 ₺ 2.800 ₺ (Mayıs kampanyası, %20 indirimli). Detaylar için katalog talebinde bulunabilirsiniz.

Token-to-face map

Which family does which job

The 24 tokens, mapped to faces.

Display drives every "designed" surface — logotype, hero, headings, eyebrows, UI labels, KPI numerals, badges. Body drives every paragraph and inline element. Mono drives code. No token uses more than one family. The system fallback resolves to native UI fonts when web fonts don't load — designed degradation, not breakage.
