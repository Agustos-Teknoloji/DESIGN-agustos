Ağustos Design System v5.0.0

Every change, one command

Edit a source. Refresh the UI kit. Stop. Logos, Office files, and fonts wait until someone asks.

Every change

Refresh the kit

Edit tokens/design-tokens.json, tokens/web.css.tmpl, brand/brands.json, or a ui/*.tmpl file. 

python3 scripts/build_design_system.py
python3 scripts/build_design_system.py --check

That overwrites the committed UI kit in ui/ and the matching CSS.

Only when asked

Full rebuild

Do not run these unless the user asks. They rebuild logos, Office files, fonts, and datasheets. 

./.venv/bin/python brand/build.py
./.venv/bin/python brand/build_templates.py
./.venv/bin/python scripts/build_ui_fonts.py
python3 brand/build_datasheet.py --pdf

Do not hand-edit ui/ (except *.tmpl and LICENSE) or brand/exports/. The next generate overwrites those files.
