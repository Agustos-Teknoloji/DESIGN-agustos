Typeface Comparison · Same System · Four Faces

Same rules. Different temperaments.

Every other variable is locked. Same hierarchy, same weights (Option A applied), same Turkish content, same English content, same brand color, same paper. The typeface itself is the only thing changing.

Each face has been tuned to its own conventions where they differ from Fraunces — for example, EB Garamond runs visually small so its sizes are bumped slightly. This is what each face actually looks like in real use, not at default sizes.

Face 01 · Current

Fraunces

Variable font with three axes (weight, optical size, SOFT). Modern revival of mid-century commercial serifs. Lots of character — slightly Western, slightly playful.

What you have now. Distinctive but assertive — the source of the "boldish" feeling even with body weight 380.

Face 02

Source Serif 4

Adobe's open-source workhorse, designed for screens. Variable with weight and optical size axes. Less character than Fraunces — more "book-default."

The conventional editorial choice. Used by NYT, Stripe Press, The Verge. Body reads quietly; bold contrasts cleanly. Less distinctive personality.

Face 03

Newsreader

Production Type's screen-optimized serif, designed specifically for long reading on devices. Variable with optical size axis (6–72) — letterforms genuinely change shape at different sizes.

The most "comfortable" of the four for long-form. Body recedes naturally, lets bold and italic do their work. Built for newsrooms.

Face 04

EB Garamond

Open-source revival of Claude Garamont's 16th-century type. The most-used serif in book history. Smaller x-height than the others — runs visually smaller, so sizes are bumped here.

Maximum "book." Quiet, traditional, gentle. Less modern than the others — more old-world editorial. Strong contrast between regular and bold built into the design.

How to evaluate

Don't read the words. Read the texture. Then read the words. Then read the bold. Then check the Turkish diacritics. Each check answers a different question.

1. Body texture

Squint at each body paragraph. Which gray feels most like "comfortable book reading" — neither aggressive nor timid? That's your body.

2. Bold contrast

Find "spesifikasyon disiplini" in each face. Which makes bold pop without shouting? Bold should announce, not yell.

3. Italic character

Read "doğru ışık, doğru yerde." Which italic feels like a different voice rather than just slanted body? Italic should sing.

4. Turkish diacritics

Check ş, ğ, ı, İ in body and italic. Do they feel proportional and considered, or grafted-on?

5. The H1

"Işığın mimariyle buluştuğu yer." Each H1 has a personality. Which voice do you want associated with Ağustos at the top of every page?

6. Long-read fatigue

Read all the body text in one face from start to finish. Does your eye want to keep going or rest? The face that doesn't tire you wins.
