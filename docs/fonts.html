Fonts

Three families. Each has one job. Load the kit fonts before the stylesheet or the page falls back to system sans.

Inter Tight — display

Logotype, hero, headings, labels, table headers, badges, pullquotes. Headings are thin: 300 on the hero and H1, 400 on H2, 500 on H3, 600 on H4. The wordmark alone uses 650.

The hero carries the page's one highlighter stroke: <mark class="type-highlight"> around one to four words of the main headline. Never on links, buttons, numbers, or body text.

Inter — body

Paragraphs, lists, links, tables, forms. Turkish letters must render: ğüşiöç İĞÜŞÖÇ. Pijamalı hasta yağız şoföre çabucak güvendi.

A link uses weight 600 and a 2px red underline. Underline is for links only. Italic marks names of publications and projects, foreign terms, and quoted phrases. Bold (600) marks a fact the reader scans for, at most once per paragraph. Never combine them.

The hero deck is upright body at 21px in ink-soft.

Footnotes use this family at 13px in ink-soft. The hero trust line uses 15.5px.

.type-body 16.5px · .type-hero-deck 21px · .hero-trust 15.5px · .type-footnote 13px

JetBrains Mono — data

Code, hex values, product SKUs, file paths. Tabular figures. Never for headings or wordmarks.

One golden scale

Every size is the 16.5px body times 1.272 per step, so every second step is the golden ratio: 13, 16.5, 21, 27, 34, 43, 55, 70, 89px. Headings shrink one or two steps on small screens. The 15.5px UI size for menus, buttons, and the trust line is the one size off the scale.

Four weights: 300 · 400 · 500 · 600. Wordmark 650.

Rules

  • Wordmarks stay lowercase Inter Tight 650. No tagline on the lockup.
  • Set lang="tr" on Turkish content so locl capitalises İ/ı correctly.
  • No uppercase labels, eyebrows, headers, or coloured text.
  • One highlighter stroke per page, on the main headline only.
  • Do not add a fourth family. Do not swap Inter Tight for a serif.
