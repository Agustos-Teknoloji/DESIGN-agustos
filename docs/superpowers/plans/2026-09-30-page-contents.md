# "On this page" contents list: implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the kit component `agustos-contents` (an "On this page" list) and put it on the IESDesk privacy notice and beta terms and on the agustos.com privacy policy in Turkish and English.

**Architecture:** The kit ships one no-script component: a native `details` element that is a folded line below 1280px and, at 1280px and wider, an open list that CSS moves into the side zone and keeps in view with `position: sticky` on `::details-content`. Each site renders the component from one shared partial or component, with an explicit list of `[id, label]` pairs, and a test proves that each item points at a real section with the same heading text.

**Tech Stack:** DESIGN-agustos (a Python generator: `tokens/web.css.tmpl` and `tokens/design-tokens.json` build `ui/agustos.css`; `unittest`), APP-iesdesk (Rails 8, ERB, Minitest, Capybara system tests in five browsers), WEBSITE-agustos (Astro 7 static site, `node --test` on the built `dist/`).

**Spec:** `docs/superpowers/specs/2026-09-30-page-contents-design.md` (DESIGN-agustos, branch `claude/page-contents-spec`).

## Global Constraints

- Kit version: `7.4.0` (from `7.3.3`). A new class is a minor version.
- Class names, exactly: `agustos-contents`, `agustos-contents__toggle`, `agustos-contents__title`, `agustos-contents__list`, `agustos-contents__link`.
- Labels: "On this page" (English), "Bu sayfada" (Turkish).
- Breakpoint: `min-width: 1280px` for the side zone. The footer already stacks at `max-width: 1279px`.
- No script in the kit component or on either site. IESDesk JavaScript rules do not change.
- Colours: `--ink-soft` for links, `--ink` on hover and focus, `--rule` for lines, the 2px `--signal` focus ring. No red text.
- Link height: at least `var(--control-min)` (44px).
- Checker rule: `AG031` (warn). AG029 and AG030 are taken.
- No text of any legal page changes. No URL changes.
- Writing: ASD-STE100 in docs, comments and commit messages; no contractions; no em dashes.
- Kit rules: edit `tokens/web.css.tmpl` and `tokens/design-tokens.json`, then run `python3 scripts/build_design_system.py`; never hand-edit `ui/agustos.css`. `ui/UI-KIT.md` stays at 200 lines or fewer.
- Worktrees: DESIGN-agustos keeps working on branch `claude/page-contents-spec` in `.claude/worktrees/page-contents-spec`. Each site gets a new worktree from `origin/main`. Never switch the primary checkout of a repository that another session owns.

## Review Focus

1. **A short laptop window (1280x720).** The nine-item privacy list with its heading is about 440px tall; the reader expects to reach the last item. The `max-block-size` and `overflow-y: auto` on `::details-content` cover it. Task 3 checks it in a browser at 1280x720.
2. **A browser without `::details-content` (Safari before 18.4, older Firefox).** The reader expects a folded line that still opens. The CSS keeps `__toggle` visible outside the `@supports` block. Task 6 opens the fold in the wide system test when the fold shows, so the test passes on both paths.
3. **A jump lands under the sticky header.** The reader expects to see the section heading after a click. Task 6 clicks "Your rights" and asserts the heading top is below the header.
4. **A renamed section.** The reader expects the list to match the headings. Tasks 6 and 8 compare each label with its heading text.
5. **Keyboard users on a wide screen.** The summary is hidden there; the reader expects Tab to reach the links. Task 6 asserts the links are visible at 1440px, and Task 3 checks Tab and the focus ring in a browser.

```python
class ContentsScan(HTMLParser):
    """Finds each .agustos-contents whose parent is not .container--reading. The
    list takes the side zone from that parent, so anywhere else it lands wrong."""

    def __init__(self) -> None:
        super().__init__(convert_charrefs=True)
        self.stack: list = []      # open tags as (name, classes)
        self.misplaced: list = []  # start lines of misplaced lists

    def handle_starttag(self, tag, attrs):
        if tag in VOID_TAGS:
            return
        classes = (dict(attrs).get("class") or "").split()
        if "agustos-contents" in classes and not (self.stack and "container--reading" in self.stack[-1][1]):
            self.misplaced.append(self.getpos()[0])
        self.stack.append((tag, classes))

    def handle_startendtag(self, tag, attrs):
        pass  # a self-closing tag holds nothing

    def handle_endtag(self, tag):
        for index in range(len(self.stack) - 1, -1, -1):
            if self.stack[index][0] == tag:
                del self.stack[index:]
                return
```
