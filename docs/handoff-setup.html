What gets reproduced, and why it is slow

Given the factory, an agent does the documented generate step. Those commands recreate files that already exist. Website work cannot start until they finish.

Apply the zip to a website

  1. Copy ui/ to vendor/agustos-ui/ in the target repository. Commit it.
  2. Paste vendor/agustos-ui/AGENTS-SNIPPET.md into that project's AGENTS.md.
  3. Load fonts first, then the stylesheet. Put a brand-* class on <body>.
  4. Use kit classes and var(--name). Open starter.html to see every class once.
  5. Run python3 vendor/agustos-ui/check-agustos-ui.py . and make it exit 0.
<link rel="stylesheet" href="/vendor/agustos-ui/agustos-fonts.css">
<link rel="stylesheet" href="/vendor/agustos-ui/agustos.css">

Read ui/UI-KIT.md before you write markup. Do not combine this stylesheet with Bootstrap or Tailwind preflight.

If a Claude Design zip arrives here

A Design session cannot write this repository. The zip is a proposed spec, not a merge. Do not copy .dc.html markup. Map values onto the three sources, then generate once.

In the Design zipEdit hereThen run

Identity ink, wordmark, brand roster brand/brands.json The line above, then brand/build.py
Page compositions in .dc.html A real website repository, not this one Nothing here. Promote later if it holds.
Decision write-up DESIGN.md and MEMORY.md after you accept the change Tests and --check

Skip brand/build.py unless identity ink, the symbol, or a wordmark changed. That rebuild is the expensive step (lockups, favicons, Office, datasheets). CSS and the UI kit do not need it.

When you should regenerate

Only inside this repository, and only after you edit a source. Website application is not that moment.

  • Token, recipe, or kit-template change → python3 scripts/build_design_system.py
  • Master font files in brand/fonts/ changed → scripts/build_ui_fonts.py
  • Identity ink, symbol, or wordmark changed → brand/build.py and templates

Open this file from the repository: python3 -m http.server 4331 --directory . then visit /docs/handoff-setup.html. Build the slim zip with python3 scripts/pack_handoff.py.
