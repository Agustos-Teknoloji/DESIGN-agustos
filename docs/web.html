Web screens

One reference page per screen type, rendered live from screens/. Each carries its brand's registered chrome. The rules under each frame come from the screens table in the registry, the same table the kit and the checker read.

Chrome per brand: agustos sidebar, pataraz topbar, pld topbar, iesdesk sidebar, specquick sidebar. Marketing, catalog, content, and document screens are light. Only product UI allows dark; open the app shell and use its theme control.
